# IDZ_IZP

Простий консольний додаток на Python для перевірки, чи є введений рядок паліндромом. 
Ігнорує пробіли, розділові знаки та регістр. Додаток обробляє помилки порожнього вводу та відправляє їх у Sentry.

## Вимоги
* Python 3.9+
* pip

## Швидкий старт

1. Створіть та активуйте віртуальне оточення:
   - python -m venv venv
   - source venv/bin/activate  # Для Linux/Mac
   - venv\Scripts\activate   # Для Windows

2. Встановіть залежності:
    make install
    Для відстеження помилок встановіть змінну оточення SENTRY_DSN у файлі .env або системі:

    - export SENTRY_DSN="ваш_dsn_ключ_з_sentry"
3. Запустіть додаток:
   - make run
